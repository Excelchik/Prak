🏙 Игровая ситуация
Умная система безопасности проверяет доступ в специальную зону. Правило: пройти можно, если пользователю исполнилось 14 лет и у него есть пропуск.

          
security.py
age = 15
has_pass = True
if age >= 14 and has_pass:
    print("Доступ разрешен")
else:
    print("Доступ запрещен")

          
📝 Задание 1 · 4 балла · Измени значения и предскажи результат

          

            

              Сценарий 1
age = 13has_pass = True

              

                
                
              

              

              
Объяснение13 >= 14 → False; has_pass → True; False and True → False. Выполняется else: «Доступ запрещен». Пропуск есть, но возраст не подходит.

            

            

              Сценарий 2 · граничное значение
age = 14has_pass = True

              

                
                
              

              

              
Объяснение14 >= 14 → True (знак «больше или равно»); has_pass → True; True and True → True. «Доступ разрешен». Граничные значения всегда стоит проверять отдельно!

            

          

          
📝 Задание 2 · 6 баллов · Мини-вопросы на and, or, not

          

            Вопрос 1 · or Что выведет программа?
            
x = 5
print(x > 3 or x > 10)

            

            

            
Объяснение5 > 3 → True, 5 > 10 → False. True or False → True: для or достаточно одного истинного условия.

          

          

            Вопрос 2 · not Что выведет программа?
            
is_raining = False
if not is_raining:
    print("Гуляем")
else:
    print("Берём зонт")

            

            

            
Объяснениеis_raining = False, not False → True, поэтому выполняется ветвь if: «Гуляем». Дождя нет — можно гулять.

          

          

            Вопрос 3 · комбинация Что выведет программа?
            
a = 5
b = 2
print(not (a > 3 and b > 4))

            

            

            
ОбъяснениеСначала скобки: 5 > 3 → True, 2 > 4 → False, True and False → False. Затем not False → True.

          

          
Робот Байт · подсказка (−1 балл)and даёт True, только если ОБЕ части True. or — если хотя бы одна. not переворачивает значение. И помни: 14 >= 14 — это True!

Базовый⭐

        
«Датчик температуры»: положительное или отрицательное?

        
Создать программу, которая проверяет, является ли число положительным или отрицательным.

        
  • ввод числа через int(input());
  • конструкция if-else;
  • понятный вывод результата.

        
Ввод: -7
Вывод: Число отрицательное

        
Бонус: подумай, что выведет твоя программа для числа 0, и добавь для него отдельную ветвь.

        
        
number = int(input("Введите число: "))
if number > 0:
    print("Число положительное")
else:
    # допиши вывод для другого случая
    ...

      

      

        
Средний⭐⭐

        
«Электронный дневник»: оценка по баллам

        
Создать программу, которая определяет оценку ученика по количеству набранных баллов, используя if-elif-else.

        
  • условная шкала для задания: 85–100 → «5», 65–84 → «4», 40–64 → «3», меньше 40 → «2»;
  • не меньше трёх ветвей elif;
  • проверить программу на граничных значениях (85, 65, 40).

        
Ввод: 72
Вывод: Оценка: 4

        
        
score = int(input("Баллы: "))
if score >= 85:
    print("Оценка: 5")
elif score >= 65:
    print("Оценка: 4")
# продолжи цепочку elif ... else

      

      

        
Повышенный⭐⭐⭐

        
«Умный дом»: своя система принятия решений

        
Разработать собственную простую систему принятия решений для умного дома, используя if, if-else и логические операции and, or или not.

        
  • минимум 3 правила (свет, отопление, сигнализация…);
  • хотя бы одно составное условие;
  • комментарий к каждому правилу: «если…, то…»;
  • связь с целью 7.3.3.1: система работает по правилам.

        
Пример правила:
if is_dark and motion: включить свет

        
        
temperature = 17
is_dark = True
motion = True
# Правило 1: свет
if is_dark and motion:
    print("Свет включен")
# Правило 2: отопление ... придумай сам

Почему игровая форма подходит семиклассникам

        
В 12–13 лет у подростков на первый план выходит общение со сверстниками, стремление к самостоятельности и признанию. Игровой сюжет «Миссия: спасти умный город» отвечает на это: ученики выступают командами разработчиков, получают роли, баллы и достижения.

        
Игровая рамка снижает тревогу при ошибке: неверный ответ — это «баг», который можно найти и исправить. Это естественно для программирования и поддерживает учебную мотивацию.

      
🎯
Как урок ведёт к целям 7.3.1.1 и 7.3.1.2

        
Задания выстроены по возрастанию сложности. Миссия 1 — простое ветвление if-else. Миссия 2 — множественный выбор if-elif-else. Вместе они покрывают цель 7.3.1.1: ученик выбирает конструкцию под задачу.

        
Миссия 3 и мини-вопросы направлены на цель 7.3.1.2: ученики записывают составные условия, вычисляют and, or, not и проверяют граничные значения. Песочница позволяет на опыте увидеть, как замена and на or меняет поведение системы.

      
🌍
Связь программирования с реальной жизнью

        
Каждая миссия моделирует систему, которую ученики видят каждый день: кодовый замок, светофор, пропускной турникет. Поэтому условие в программе воспринимается как правило, по которому работает реальное устройство, а не как абстрактная запись.
